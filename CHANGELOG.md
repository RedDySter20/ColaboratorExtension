# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [2.0.0] — 2026-11-27

Полная переработка проекта: читаемая модульная архитектура, тесты, CI, новый
интерфейс и документация.

### Добавлено

- **Инспектор взаимодействий**: разбор HTTP-запроса/ответа, DNS-вопроса
  (wire-формат, QTYPE), SMTP-диалога; «интересные» заголовки (`Authorization`,
  `Cookie`, `X-Api-Key`, …) выводятся отдельными полями.
- **Три режима просмотра** payload'ов: printable-текст с байтовыми подсказками,
  hexdump с offset'ами и ASCII-гуттером, извлечение печатных строк.
- **Отчёт в Markdown** по одной сессии или по всей базе — с таблицей
  взаимодействий и сворачиваемыми блоками сырых запросов.
- **Свои серверы**: редактирование Public/Private URL и secret для self-hosted
  interactsh (включая AES-256-CTR-расшифровку ответов).
- **Настройки**: интервал опроса, лимит хранения логов, тема, домен по
  умолчанию, уведомления, авто-возобновление, поведение при открытии сессии.
- **Страница настроек** со статистикой хранилища, экспортом/импортом и
  управлением optional host permissions.
- **Уведомления и бейдж**: одно системное уведомление на цикл опроса, счётчик
  непрочитанного на иконке.
- **Поиск по декодированному содержимому** взаимодействий, фильтры по протоколу,
  пагинация журнала и навигация с клавиатуры.
- **ESLint 9**, **Prettier**, `npm run check`, GitHub Actions CI и релизный
  workflow.
- **Скрипт сборки** `scripts/build.mjs` (валидация manifest, ссылок и графа
  модулей) и генератор ZIP без внешних зависимостей.
- **Иконки расширения** (16/32/48/128) и скриншоты для документации.

### Изменено

- Код разделён на `core/` (чистая логика) и `ui/` (контроллеры страниц);
  минифицированные `0.js`…`3.js` заменены на именованные ES-модули.
- UI переработан: тёмная/светлая темы без вспышки, тосты вместо `alert()`,
  модальные подтверждения вместо `confirm()`, доступность с клавиатуры.
- Импорт стал устойчивым: принимает JSON v1/v2, legacy base64 и «сырые» массивы
  сессий; режимы «объединить» и «заменить».
- Экспорт по умолчанию — читаемый JSON вместо base64-обёртки.
- Версия manifest: 1.3.3.7 → 2.0.0.

### Исправлено

- Дублирование взаимодействий, если сервер возвращал их повторно
  (дедупликация по fingerprint с индексом в IndexedDB).
- `alert()`/`confirm()` больше не блокируют popup (в popup они могли не
  отображаться).
- Ошибки сети/таймауты теперь видны в интерфейсе (`HTTP 5xx`, текст ошибки,
  бейдж «ошибка»), а не только в консоли service worker.
- Переполнение стека при base64 больших payload'ов (кодирование чанками).
- Поиск по журналу больше не зависит от base64-представления.
- Сортировка и лимиты сессий/логов проверяются на уровне репозитория.

### Совместимость

- Формат генерации сессий не изменился — старые сессии и URL продолжают работать
  (golden-тесты против версии 1.3.3.7).
- Схема IndexedDB обновлена до v2 добавлением индекса `fingerprint`;
  существующие данные сохраняются.
- Формат экспорта v1 (base64-JSON) по-прежнему принимается при импорте.
